# Command Center for Okta

A read-only side panel for Okta administrators, by Fenil Panchal.

It sits beside the Okta admin console and answers the questions the console
makes you assemble by hand: how each person got each application, what a group
rule really selects, what a rule change would add and remove before you save
it, and what needs your attention in the org, worst first.

It reads your own Okta org with the session you already have, changes nothing,
and sends nothing anywhere else.
